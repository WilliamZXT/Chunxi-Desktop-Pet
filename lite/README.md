## English

This folder preserves the original ChatGPT/Codex host-pet snapshot: `pet.json` and `spritesheet.webp`. Chunxi Desktop Pet is a separate standalone Windows application and does not depend on Lite. Available actions, installation and compatibility are controlled by the host; placing this folder next to the desktop app does not register a pet automatically.

This pass updates documentation only. It does not re-register Lite, change its assets or claim compatibility with every host version. For the Windows desktop pet, download the published Windows package from the [English homepage](../README.en.md). Lite artwork is also excluded from the code's MIT license; see [licensing boundaries](../docs/LICENSE-OPTIONS.md).
