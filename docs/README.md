## 开发资料的语言范围 / Developer-language scope

依赖清单、VERSION、Windows 版本资源、JSON 键、内部测试和实现注释保留机器/开发格式，不强行逐句双语。标准 MIT 正文保留英文原文，适用范围和美术边界另有双语说明。现有程序 UI/日志未在本轮改写；使用指南翻译菜单与常见启动提示。

Dependency pins, VERSION, Windows version resources, JSON keys, internal tests and implementation comments retain machine/developer formats rather than forced line-by-line translations. Standard MIT legal text stays in English, with bilingual scope/artwork guidance. Existing app UI/logs are unchanged; the user guide translates menus and common launcher messages.
