# 安全与问题报告 / Security and issue reporting

## 中文

当前公开版本为 [v0.1.1](https://github.com/WilliamZXT/Chunxi-Desktop-Pet/releases/tag/v0.1.1)；没有承诺的安全支持周期或响应时限。Windows 未签名提示、下载核验与排错见 [Windows 安全说明](docs/SECURITY-AND-WINDOWS.md)。

普通问题请提交到 [Issues](https://github.com/WilliamZXT/Chunxi-Desktop-Pet/issues)，提供版本、复现步骤和脱敏日志。不要在公开 Issue 放置令牌、密码、个人配置或私人路径。敏感漏洞优先使用 GitHub 私密漏洞报告（如果仓库已启用），或通过维护者已公开提供的联系渠道请求私密沟通；本项目尚未列出专用安全邮箱，不虚构联系方式。本轮未启用或验证私密报告设置。

## English

The current published version is [v0.1.1](https://github.com/WilliamZXT/Chunxi-Desktop-Pet/releases/tag/v0.1.1). No security-support period or response-time commitment is promised. See [Windows security notes](docs/SECURITY-AND-WINDOWS.md) for unsigned-app warnings, download verification, and troubleshooting.

Use [Issues](https://github.com/WilliamZXT/Chunxi-Desktop-Pet/issues) for ordinary bugs with the version, reproduction steps, and sanitized logs. Do not post tokens, passwords, personal configurations, or private paths publicly. For sensitive vulnerabilities, prefer GitHub private vulnerability reporting if enabled, or request a private channel through contact information the maintainer has publicly provided. No dedicated security email is currently listed or invented. This pass does not enable or verify private-reporting settings.
